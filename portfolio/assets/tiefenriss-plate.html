The honest conclusion

The value model — the heart of the system — is not externally anchored to any generic exploitation signal, across two operating systems and three independent ground-truths. The central hypothesis was not supported.

There is a real tension I state rather than bury: the design intends value to be perspective-relative — an exploit developer's notion of a good primitive is not a generic attacker's likelihood of mass-exploitation. The null results are consistent with that intent — yet that same intent is what makes the model hard to falsify with generic data. Whether the eye is a genuine predictor or a perspective-relative heuristic is the open question the project ends on, honestly unresolved.

03 What it demonstrates

System design

Four layers with clean, independently-testable seams; a sealed core that absorbed a second domain by adding one module — no rewrite.

Epistemic discipline in code

Measured / derived / open / quarantined as first-class status, with a barrier that stops "unknown" being used as "known".

Research method

Pre-registered expectations, controlled & partial-correlation tests, and a reusable backtest harness that settles a hypothesis in minutes, not months.

Intellectual honesty

Killed my own most-cherished idea three times over, and accepted the decisive negative result instead of rationalizing it.
